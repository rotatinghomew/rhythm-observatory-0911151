# 不规则观测的周期与跨平台同步分析（rhythm-sync-v1）

自然日相加曲线隐含等距、无缺失的假设，与计数器的真实观测时刻不符。本方法直接在
时钟校正后的不规则观测时刻上工作，不重采样、不补零，产出可以回溯到原始读数与
时钟规则版本的周期与同步结论。

## 输入口径

* 累计计数先按相邻读数换算为区间增量；计数器重置后的首条读数不产生增量，负增量
  保留 `counter_anomaly` 标记且不参与为负事件。
* 增量除以区间真实时长得到单位时间计数率，时间戳取区间中点；时间一律使用
  `clocked_readings` 选择后的校正时间，并同时保留原始时间。
* 停测区间（outages，左闭右开）在原始时间轴上匹配，横跨停测的增量标记
  `gap_spanning` 与对应 outage id；没有观测不等于没有阅读，停测区间不补零。
* 时钟规则按设备与区间选择，重叠时按公开日期和 revision 取更新者；每条派生记录
  保留 `source_readings`、`clock_records`、`clock_versions`。

## 单平台周期

1. 在均匀频率网格上计算 Lomb-Scargle 归一化周期图，适用任意不规则采样时刻。
2. 同时计算采样窗口谱（观测时刻放单位值的非归一化傅里叶幅度）。候选峰处窗口功率
   高，说明峰由采样节律制造，标记 `sampling_induced=true`，不能作为内容周期。
3. 显著性用时序置换代理：保持观测时刻不变、打乱取值，在 72-336 小时内容节奏频带
   内取代理谱最大值，对频带内多重搜索做族系校正；`surrogate_p_value < 0.05`、
   覆盖至少 3 个周期且非采样诱导，才判为 `period_detected`，否则为
   `period_not_established`。
4. 候选周期在粗峰附近以残差平方和最小化细化，并给近似 95% 置信区间；相位由同频
   余弦/正弦最小二乘得到，不确定性用 bootstrap 的环形 95% 区间表达。
5. 短时突发按中位数 + 4×MAD 标记，与停测横跨增量一起做剔除复算，结论附
   `robustness=stable/sensitive`。

## 跨平台同步

* 只在两地校正后覆盖时段的真实交叠窗口内比较，窗口与双方观测点数随结果返回。
* 先在交叠窗口内分别重估周期并重新做代理检验：双方显著、周期近似置信区间相交且
  点估计差不超过 6 小时，才认定共同周期；否则状态为 `periods_not_comparable`。
* 共同周期成立后拟合各自相位，相位差的 95% 区间由成对 bootstrap 给出，并做
  共同相位模型对各自相位模型的 F 检验。
* 三档结论：
  - `phase_consistent`：相位差区间包含零、宽度不超过周期的 12%，且同相位模型
    未被拒绝——支持按共同节奏排期；
  - `synchrony_inconclusive`：共同周期成立但相位差区间过宽——只说明各自有周期，
    不足以比较同步，排期端收到 `separate_rhythms_only`；
  - `phase_distinct`：同相位假设被拒绝或零不在区间内——共同周期存在但应分相位排期。
* 一方周期未确立时给 `no_shared_rhythm_claim`，不输出共同节奏结论。

## 记录追查

`trace_period(snapshot, platform, start_hour, end_hour, period_hours=None)` 在指定
校正时间窗口内重估或按给定周期拟合，返回每条记录的来源读数、时钟规则、时钟版本、
原始/校正时间、观测率、拟合值与残差，以及停测标记。窗口内观测点不足或平台不存在
时抛错，不返回看似精确实则无支撑的结果。

## 发布与回溯

成果通过 `workflow.publish_rhythm` 以方法名 `rhythm-sync-v1` 发布，包含 `as_of`、
`snapshot_id`、方法配置与完整结果；服务端校验资料指纹，成果不可变。读回成果后可
经 `supporting_records` 与 `trace_period` 回到对应原始时间和时钟校正版本。浮点数
均为有限值，缺失信息用 `null` 与显式状态表达。
